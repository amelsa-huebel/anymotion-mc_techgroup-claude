# Memory layout

- `unsorted/` — raw learnings as captured by `/learnsave` (one file per session)
- `distilled/` — actionable beliefs after `/formulate-beliefs` runs
- `archived/` — old learnings rolled out of distilled (kept for audit)

Project-scoped memory complements (does not replace) the central hub at
`~/my-assistance/memory/`. Use the `-global` variants of the same commands
when a learning applies across all your Pimcore work.
